**Навигация:**
```
gg        — в начало файла
G         — в конец файла
0         — в начало строки
$         — в конец строки
3G        — перейти на строку 3
w         — следующее слово
b         — предыдущее слово
```

**Редактирование:**
```
x         — удалить символ
dd        — удалить строку
3dd       — удалить 3 строки
dw        — удалить слово
u         — отменить
Ctrl + r  — повторить
```

**Копирование:**
```
yy        — копировать строку
3yy       — копировать 3 строки
p         — вставить после
P         — вставить перед
```

**Поиск:**
```
/word     — искать "word"
n         — следующее совпадение
N         — предыдущее совпадение
```

**Замена:**
```
:%s/old/new/g   — заменить все "old" на "new"
```

**Вставка:**
```
o         — новая строка снизу
O         — новая строка сверху
A         — вставка в конец строки
```

**Разделение окна:**
```
:vsplit   — разделить вертикально
:split    — разделить горизонтально
Ctrl+w w  — переключиться между окнами
:q        — закрыть окно
